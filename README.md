# Roblox FPS Marketplace

This project is a basic First-Person Shooter (FPS) game with a shop system for purchasing RBX items in Roblox. It includes player movement controls, basic FPS mechanics, a weapon system with different weapons, and a shop system for purchasing items using RBX currency.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the `PlayerScript.server.lua`, `WeaponSystem.server.lua`, and `ShopSystem.server.lua` scripts in the appropriate locations in your Roblox Studio project.

## Use

1. Place the scripts in the appropriate locations in your Roblox Studio project.
2. Customize the weapon properties and shop items as needed.
3. Test the game in Roblox Studio to ensure everything works correctly.
